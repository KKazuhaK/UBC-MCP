# UBC Course Capture 隐私政策

[English](extension-privacy.md)

UBC Course Capture 是一个 Chrome 和 Firefox 浏览器扩展。它在你的浏览器里读取
UBC Workday 页面上的课程和注册信息，发送到你选择的 MCPHub 服务器上的 UBC
connector，让你连接到该服务器的 AI 助手可以用你自己的数据规划选课。它是独立的
开源项目，不由 UBC 或 Workday 制作，也与它们无关。

本政策适用于扩展 0.4.1 及以后的版本；更早版本的说明见本文件的修改历史。源代码公开在
https://github.com/KKazuhaK/UBC-MCP ；扩展代码在 `src/collector/` 和
`extension/`，服务端在 `src/connector/`。

## 概要

- 扩展只有在你授权之后才读取 UBC Workday 页面（`https://wd10.myworkday.com/ubc/`），
  并且只把识别出的课程和注册信息发送到你填写的 MCPHub 地址。扩展没有内置任何服务器地址。
- 扩展从不读取你的 Workday 密码和 Cookie。你的姓名、学号和页面上的其他内容不会被
  发送：注册信息的采集方式就是为了去掉你的姓名和学号。
- 没有统计、追踪或广告，数据不会出售。
- 运行该 MCPHub 服务器的人（运营者）可以读取扩展上传的数据。请使用你信任的运营者的服务器。

## 扩展发送什么

**课程班次。** 来自任何扩展能识别出课程班次列表的 UBC Workday 页面（课程搜索结果
和班次详情对话框，也包括版式相同的其他 Workday 视图，比如已保存的课表）：课程和
班次代码与名称、授课形式、注册状态、教师姓名、班次容量、已注册和候补人数及其上限、
保留和非保留座位数、保留座位的资格规则及对应座位数、资格说明、必修的配套活动、
上课的星期、时间、日期和地点、学期和校区，以及 Workday 为每个班次分配的内部标识。
采集哪些班次取决于页面显示的内容，所以它也可能反映你搜索或规划了什么。

**你的注册记录。** 来自具有 View My Courses 表格各列的 Workday 表格：你已注册或在
候补中的每门课的班次代码和名称、授课形式、上课安排、教师、Workday 的班次标识，
以及你是已注册还是候补。其他状态的行会被丢弃。该表格第一列包含身份信息，扩展只
从中匹配学期，其余内容全部丢弃。

**读取但不发送的内容。** 为了找到上述内容，扩展的脚本会在你的浏览器里读取它所运行
的每个 UBC Workday 页面的全部内容，包括文字和表格。这些页面上的任何内容，比如页面
上显示的姓名、学号、成绩或财务信息，都留在你的浏览器里，也不会被保存。

**从不读取的内容。** Workday 密码、Cookie 或会话令牌；浏览历史；除下文所述的
MCPHub 授权步骤外，UBC Workday 以外的任何页面。

## 什么时候读取

- **「Connect with MCPHub」会开启自动同步**，点击后立即开启，即使你没有完成连接。
  你可以随时点「Pause automatic sync」暂停。
- **后台同步注册记录。** 开启同步约一分钟后，以及之后浏览器运行期间每 15 分钟，扩展
  会让浏览器在后台标签页打开 View My Courses，使用你现有的 Workday 登录状态。它读取
  页面、上传结果，然后关闭该标签页（如果你切换到了这个标签页，它会保留不关）。如果你
  未登录，就什么也读不到。
- **你打开的页面。** 自动同步开启时，扩展也会在你打开的每个 UBC Workday 页面上运行。
  页面显示可识别的课程班次或完整的注册表格时，它会在页面变化几秒后上传，页面保持打开
  期间大约每四分钟再上传一次。
- **手动操作。** 「Sync now」立即执行上述同步。其他按钮只在你点击时运行：「Preview
  course sections」和「Preview my registrations」读取当前 Workday 标签页；导入导出的
  JSON 文件时会校验你选择的文件；预览或导入的内容在你点「Upload previewed data」之前
  不会上传。「Export course snapshot」和「Export my registrations」只保存文件，不上传。

## 数据发往哪里

扩展只通过 HTTPS 向你填写的 MCPHub 地址发送数据，并且不带浏览器 Cookie：

| 请求 | 时机 | 发送内容 |
| --- | --- | --- |
| `GET /ubc/capabilities` | 点「Connect with MCPHub」时 | 仅普通请求本身 |
| `POST /ubc/api/claim` | 你批准连接后 | 一次性代码 |
| `POST /v1/snapshots` | 每次同步或上传 | 一份快照（上述数据）和你的上传凭证 |

和所有网络请求一样，这些请求会让该服务器看到你的 IP 地址、请求时间和浏览器版本，
并带有扩展自己的来源（`chrome-extension://…` 或 `moz-extension://…`）。扩展本身
不向 Workday 发送请求；它打开的后台标签页是浏览器的普通页面加载，带着你的 Workday
Cookie，和你自己打开一样。

**连接。** 「Connect with MCPHub」会在新标签页打开你的 MCPHub 上的 UBC 连接页，你在
那里登录 MCPHub 并批准。随后扩展只在这个标签页里运行一个小脚本，读取页面交给扩展的
一次性代码，不读取你的 MCPHub Cookie、资料或会话，再用这个代码换取上传凭证。

**下载。** 导出会把 JSON 文件保存到你选择的位置。它是上述数据未加密的明文副本，
请自行妥善保管。

## 浏览器里保存什么

保存在扩展的本地存储中（不会在你的设备间同步）：MCPHub 地址和上传凭证；是否开启
自动同步；上次同步的时间、数量和上次同步错误；上一次连接尝试的状态（连接过程中是
把授权标签页与扩展对应起来的随机值、过期时间和标签页编号；之后是地址和成功或错误
信息）。0.4 之前版本保存的凭证（当时不保存地址）不会被使用，会一直留到你重新连接或点
「Disconnect this browser」为止。「Disconnect this browser」会删除以上所有内容，只保留
MCPHub 地址用于预填输入框。

采集到的课程数据不会写入存储。它在预览或上传期间保存在内存中；Workday 标签页里的
脚本会保留一份上次发送的内容，用于跳过没有变化的上传，直到该标签页关闭或刷新。

上传凭证可以向你的连接写入快照并替换旧快照，不能读回快照。

## 服务器上

UBC connector 是 MCPHub 中接收快照的部分，由你所填写的 MCPHub 的运营者运行。它会：

- 校验每份快照的格式，在你自己的连接下，每个校区、学期和类型（课程班次或注册记录）
  只保留最新的一份，最多 20 份；
- 用 AES-256-GCM 加密快照内容，密钥文件和数据库放在同一个数据目录里，因此运营者可以
  解密，该目录的备份同时包含数据和密钥。校区、学期、类型和采集时间以明文形式与之一起保存；
- 保存快照直到被更新的快照替换或你断开连接为止，不会按时间自动过期；
- 以明文保存你的 MCPHub 用户名（通过 OAuth 建立的连接则是签发方和账号标识）、连接的
  标签、凭证和待用一次性连接代码的哈希及其过期时间；加密保存你的凭证副本；并仅在内存中保存
  近期 IP 地址用于限流。

**谁能读取。** 持有你连接的读取凭证的人，MCPHub 会替你保存该凭证；如果启用了
connector 自己的 MCP 端点，还包括通过所配置的登录服务以你的账号登录的任何 MCP 客户端。
当你连接的 MCP 客户端或 AI 助手调用 UBC 个人工具时，你的快照会交给该客户端，并由它
交给其 AI 服务商，适用该服务商自己的政策。运营者也可以读取已保存的数据。MCPHub 的
活动日志可能记录每次工具调用（工具、用户、时间、IP 地址），并可能保存工具的输入和
输出，除非关闭了内容记录，或该调用使用按用户的凭证（UBC 个人工具通常如此）。服务器
或其托管服务也可能按运营者自己的保留策略保留请求日志和备份。

**删除。** 在 MCPHub 的 UBC 连接页点「断开并删除我的数据」，会撤销你的凭证，并从
connector 删除你当前的快照和账号关联；只保留一条已撤销的连接记录及其标签和凭证哈希。
已删除的行在被覆盖之前可能仍残留在数据库文件中。已进入备份或已经发给 AI 客户端的副本
按各自的保留规则处理。扩展里的「Disconnect this browser」只删除浏览器里的凭证和设置；
在连接页断开之前，你的数据仍留在服务器上。卸载扩展会删除它的本地存储。

## 权限

| 权限 | 用途 |
| --- | --- |
| 访问你的 MCPHub（可选，`https://*/*`，实际只申请你填写的地址） | 连接和上传；连接时申请 |
| 访问 `https://wd10.myworkday.com/*`（可选） | 自动同步时读取 Workday 页面；连接或开启同步时申请 |
| `activeTab`、`scripting` | 读取你预览的 Workday 标签页；在 Workday 标签页运行同步脚本，在 MCPHub 标签页运行授权脚本 |
| `alarms` | 每 15 分钟同步注册记录 |
| `storage` | 保存上文列出的连接和设置 |
| `downloads` | 保存你要求导出的 JSON 文件 |

扩展不下载任何远程代码，所有脚本都打包在安装包内。在 Firefox 中，扩展通过 Firefox
的数据同意机制声明它会传输：身份验证信息（一次性代码和上传凭证）、个人身份信息（教师
姓名，以及与你账号关联的注册记录）和网站内容（Workday 课程数据）。

## Chrome 应用商店用户数据

UBC Course Capture 对用户数据的使用遵守 Chrome 应用商店用户数据政策，包括其中的
有限使用（Limited Use）要求。数据只用于扩展的单一用途，即把你的 UBC 课程数据同步到
你自己的连接；不用于广告、信用或借贷决定，不会出售，除本政策所述情形外不会转移。
